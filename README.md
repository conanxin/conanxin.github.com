## About this repository

This repository preserves the source of my long-running personal blog, built with **Jekyll**, **Markdown**, and **GitHub Pages**. It began as a place to learn web publishing and keep notes, essays, quotations, and experiments in public.

The repository is intentionally kept as an archive of that earlier writing period rather than rewritten into a modern site.

## Why keep it public?

Old personal sites are useful records of how people learned, wrote, and built on the early social web. Keeping the source public also makes the repository a small reference for anyone exploring older Jekyll / GitHub Pages setups.

If this archive or its old-school Jekyll setup is useful to you, a ⭐ helps other people discover it.
